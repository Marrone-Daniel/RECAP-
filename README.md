## 为什么做这个

理解 π*0.6 的 RECAP 花了一番功夫（其实也没多久），于是做了个交互式可视化小工具，希望帮同样感兴趣的友友们一起学明白！

我最想弄清楚的，不只是流程图里有哪些模块，而是：

- 一条成功、失败或人工接管的轨迹，进入训练后变成了什么？
- 价值分布怎么变成一个数？这个数又怎么参与优势计算？
- 为什么整条轨迹成功了，其中一些动作片段仍然被标成 `0`？
- 人工纠正的标签，和通过优势阈值筛出来的标签有什么区别？

这个工具把这些中间步骤展开，让你可以自己改参数、看变化。

> [!IMPORTANT]
> 这是一个**机制与数据流的教学模拟器**，不是 π*0.6 的训练实现，也不是官方项目。页面中的轨迹、价值预测、分布形状及迭代结果均为教学设定，不代表真实模型性能。

## 快速上手

### 打开方式

1. 下载仓库：点击 GitHub 页面上的 **Code → Download ZIP**。
2. 解压后，用浏览器打开 `recap-interactive.html`。
3. 不需要安装 Python、配置模型或准备 GPU，网页可以离线使用。

单独下载时，请保存[完整 HTML 文件](./recap-interactive.html)，不要只复制网页源代码的一部分。GitHub 的文件预览页展示的是代码，不是正在运行的交互页面。

### 第一次，按这个顺序看

| 顺序 | 操作 | 重点看什么 |
| :---: | --- | --- |
| **01** | 点击「自动模拟」，或逐次点击「下一步」 | 数据如何经过采集、价值评估、标签生成与策略更新 |
| **02** | 在「示例轨迹」中选择一条轨迹 | 自主成功、失败和人工接管的数据有何差别 |
| **03** | 拖动「检查时刻」，或点击表格里的时间点 | 当前样本的回报、价值、优势和最终标签 |
| **04** | 调整左侧参数 | 右侧分布曲线、阈值与标签怎样变化 |

电脑端可以边调整参数边看右侧曲线；手机端可切换「价值分布」与「优势判别」。右上角可切换玫粉色夜间主题。

## 一条数据会经过什么

```text
示教初始化策略
      ↓
自主执行，必要时人工接管
      ↓
汇总轨迹与终局成功标签
      ↓
构造回报监督，训练价值函数
      ↓
计算动作窗口的优势 → 生成二值条件标签
      ↓
训练优势条件动作策略
      ↓
以 positive 条件部署 → 可继续采集下一轮
```

页面里的动画展示这些阶段的衔接，**不会真的采集机器人数据或执行模型训练**。

## 四个小实验

### ① 成功了，为什么还有 `0`？

选择「完整自主成功」，依次查看不同时间点。

区分两个问题：**整段任务最后是否完成**，与**这个动作窗口是否达到了优势阈值**。前者是轨迹结果，后者是动作策略的条件标签；它们不是同一个标签。

### ② 往后看 10 步，和往后看 50 步有什么不同？

选定一个时间点，调整「优势窗口 N（步）」。既可以拖动滑块，也可以直接输入数字。

观察窗口累计回报、窗口末状态价值和优势的变化。接近终点时，实际可用窗口会缩短；到达终点后，没有后续动作片段，不再生成动作优势标签。

### ③ 曲线不同，为什么标签没变？

切换窄单峰、宽单峰、左长尾、右长尾、双峰和均匀分布，对比原始单峰。

本工具切换形状时保持所设期望，因此**形状可以不同，期望却相同**。若参与计算的期望和窗口回报都没变，优势与标签也不会因此改变。

### ④ 人工纠正为什么会多出一些 `1`？

选择「第 60 步人工接管并成功」，查看接管后的非终点样本，切换「人工纠正强制标为正优势」。

- **开启**：人工纠正片段的条件标签直接设为 `1`。
- **关闭**：作为对照，按优势与阈值比较来判别。

这个规则覆盖的是**条件标签**，并不会把回报或算出的优势改成正数。因此，加入人工纠正规则后，最终正标签比例不一定等于设置的排名标正比例。

## 参数速查

| 参数／选项 | 用来观察什么 |
| --- | --- |
| 采集方式、成功轨迹比例、接管轨迹比例 | 不同数据构成在模拟流程中的变化 |
| 每轮新采集轨迹、迭代轮数 | 多轮采集与数据累计；不是性能预测 |
| 优势窗口 `N` | 从当前时刻向后看多长的动作窗口，支持输入 `1–100` 步 |
| 当前价值期望、窗口末状态价值 | 改变当前状态和未来状态的价值估计 |
| 窗口累计回报 | 改变这段动作窗口实际累积的回报 |
| 价值分布形状、形状尺度 | 比较概率如何分配；形状尺度不等同于实际标准差 |
| 优势排名标正比例 | 改变示意优势参考分布上的分位数阈值，不是调整任务成功率 |
| 人工纠正强制标为正优势 | 对比启用／关闭人工纠正标签覆盖规则 |
| 保留失败与低优势轨迹 | 对比保留数据与过滤数据的教学情形 |
| 恢复所选样本 | 撤销当前手动试算，重新加载表格中的示例样本 |

## 曲线背后的计算

### 分布 → 价值期望

页面用 201 个离散桶表示价值分布。每个桶有一个取值 $z_k$ 和一个概率 $p_k$，显示的价值是它们的加权平均：

$$
V = \sum_k p_k z_k, \qquad \sum_k p_k = 1.
$$

它不是取最高峰，也不是取中位数。这里的概率由教学形状构造，**并非模型训练得到的预测**。

### 价值与回报 → 优势

页面采用以下未折扣的窗口计算：

$$
A_t = R_{t:t+n} + V_{t+n} - V_t.
$$

其中，$R_{t:t+n}$ 是窗口累计回报，$n$ 是实际可用窗口长度，可能小于指定的 $N$。进入终止态后不再自举未来价值。

例如：当前价值为 $-0.65$，窗口末价值为 $-0.42$，累计回报为 $-0.10$，则：

$$
A_t = -0.10 + (-0.42) - (-0.65) = 0.13.
$$

### 优势 → 二值条件

对自主动作片段，页面将优势与阈值 $\varepsilon$ 比较：达到阈值标为 `1`，低于阈值标为 `0`。人工纠正覆盖规则开启时，纠正片段直接标为 `1`。

> [!NOTE]
> 页面中的阈值来自**预设优势参考分布的分位数**，不是对示例表格逐行排序算出来的。真实实验应依据对应任务的数据优势分布确定阈值。

## 常见疑问

<details>
<summary><strong>标签为 0，是不是说明动作失败了？</strong></summary>

不是。它表示当前片段没有达到所用优势阈值，不能直接等同于动作错误或整段任务失败。阈值也不一定是零。

</details>

<details>
<summary><strong>我改了滑块，为什么表格没有跟着改？</strong></summary>

手动调整价值和回报属于试算，不会改写表格中的原始示例。页面会提示「手动试算」；点击「恢复所选样本」即可重新对齐。

</details>

<details>
<summary><strong>这里的曲线就是论文训练出的分布吗？</strong></summary>

不是。价值分布形状、未来价值插值和优势参考分布都是教学设定。它们用于解释计算关系，不能作为论文实验结果或真实模型不确定性的证据。

</details>

<details>
<summary><strong>分享给别人后，大家会同步看到我的操作吗？</strong></summary>

不会。每个人在自己的浏览器中独立操作。一起讨论时，可以分享所选轨迹、时间点、窗口长度和参数，复现同一个例子。

</details>
