# RECAP 可视化小工具

理解 π*0.6 的 RECAP 花了一番功夫（其实也没多久），于是做了个交互式可视化工具，希望帮同样感兴趣的友友们一起学明白！

下载后，用浏览器打开 `recap-interactive.html` 就能用，不需要安装其他东西。

## 1. 先设置数据，看一遍流程

「采集方式」选择自主执行还是加入人工接管；「成功轨迹比例」「接管轨迹比例」调整模拟数据的构成。「每轮新采集轨迹」和「迭代轮数」决定每轮采多少、演示几轮。

点「自动模拟」看完整流程，也可以用「上一步／下一步」慢慢看。流程会依次经过采集、汇总数据、训练价值函数、计算优势、更新策略和再次部署。勾选「完成后进入下一轮采集」可以继续循环，点「重置」重新开始。

## 2. 选一条轨迹，看看里面的数据

在「示例轨迹」里选择自主成功、自主失败，或第 60 步人工接管后成功。

拖动「检查时刻」，也可以直接点表格中的时间点，查看这一步的回报标签、价值估计和优势判别。选不同轨迹、不同时间点，对比它们哪里不一样。

## 3. 调整窗口和价值，看曲线怎么变

「优势窗口 N」决定从当前时刻往后看多少步，可以拖滑块，也可以直接输入数字。窗口变了，累计回报、未来价值和优势也会跟着重新计算；接近结尾时只计算剩余的步数。

「当前价值期望」「窗口末状态价值」「窗口累计回报」可以手动调整，右侧会同步显示曲线和优势计算结果。手动试算不会修改表格中的原样本，点「恢复所选样本」就能恢复。

「价值分布形状」可以切换单峰、长尾、双峰、均匀等形状，「形状尺度」调整分布的展开程度。这里切换形状会保持期望，所以曲线变了，优势和标签不一定变。

## 4. 看优势怎么变成 0 或 1

调整「优势排名标正比例」，观察右侧阈值线移动。自主动作片段的优势达到阈值，标为 `1`；低于阈值，标为 `0`。这个比例不是成功率，标签为 `0` 也不代表整条轨迹失败。

把「当前样本来源」切换成人工纠正片段，再打开「人工纠正强制标为正优势」，标签就会直接设为 `1`；关掉则按阈值判断。它只改变标签，不会把算出的优势改成正数。

## 5. 看这些标签怎样用于策略更新

「保留失败与低优势轨迹」用来对比保留和过滤这些数据的情形。保留时，策略通过不同条件学习正、负优势数据；模拟进入部署阶段后，使用的是 `positive` 条件。

看不明白当前结果时，可以点「解释当前判别」。右上角可以切换夜间主题；手机端可以在「价值分布」和「优势判别」之间切换。

---

这里的数据和曲线都是教学模拟，不是真实训练结果；阈值也由预设的优势参考分布计算，不是从表格里的几条样本统计出来的。可以配合[原论文](https://arxiv.org/abs/2511.14759)一起看。
